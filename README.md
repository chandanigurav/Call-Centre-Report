# Call-Centre-Report
# 📊 Call Centre Report Dashboard (Excel)

## 📌 Project Overview
This project is an interactive **Call Centre Dashboard** created in Microsoft Excel.  
The dashboard helps analyze call centre performance using different KPIs, charts, and reports in a visually appealing format.

It provides insights into:
- Total Calls
- Revenue/Amount
- Call Duration
- Average Ratings
- Happy Callers
- Monthly Call Trends
- Gender-wise Call Distribution
- Representative-wise Performance
- Region-wise Analysis

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Dashboard Design Techniques

## 📈 Dashboard Features

### ✅ KPI Cards
The dashboard contains important KPI metrics:
- Total Calls
- Total Amount
- Total Duration
- Average Rating
- Happy Callers

### ✅ Monthly Call Trend
Shows the number of calls received month-wise from January to December.

### ✅ Female vs Male Callers
Compares male and female callers across different cities.

### ✅ Ratings Analysis
Displays customer ratings distribution.

### ✅ Representative Performance
Analyzes call representatives (R01–R05) based on:
- Number of Calls
- Revenue Generated

### ✅ Regional Analysis
Shows detailed data for:
- Cincinnati
- Cleveland
- Columbus

---

## 🎯 Objective of the Project
The main objective of this dashboard is to:
- Monitor call centre performance
- Track customer satisfaction
- Identify top-performing representatives
- Analyze monthly trends
- Improve business decision-making using data visualization
